# StarFighter — 3D 비행 슈팅 프로토타입

F-104를 조종하며 적을 처치하고 카드로 기체를 강화하는 Three.js 기반 웹 게임입니다. 현재 구현은 **스테이지별 3·4·5웨이브 → 보스 → 정비창 → 다음 스테이지**로 이어지는 런 구조입니다.

문서 확인 기준: 2026-09-20, 현재 작업 트리의 코드. 장기 기획과 구현 현황은 [기획안](문서/StarFighter키우기_기획안_v2.md), 개발 구조는 [ARCHITECTURE](docs/ARCHITECTURE.md)를 참고하세요.

레벨·무기·웨이브/적·카드는 `balance/`의 XLSX 원본에서 관리합니다. 수정 후 `npm run balance:build` 또는 `python tools/balance/build.py`를 실행하면 CSV 검토본, 엔진 중립 JSON, 웹용 JS가 생성됩니다. 자세한 절차는 [밸런스 데이터 안내](balance/README.md)를 참고하세요.

게임 서버 실행 중 `http://localhost:8000/balance.html`을 열면 Balance Lab에서 평균 런 시간, 성장 곡선, 적 구성, 무기 DPS, 경험치 곡선과 카드 선택 전략을 시뮬레이션할 수 있습니다. CLI에서는 `npm run balance:simulate`를 사용합니다.

## 실행

Node.js가 설치된 프로젝트 폴더에서 실행합니다. 런타임 npm 의존성 설치나 빌드는 필요하지 않습니다.

```sh
npm start
# npm을 사용할 수 없다면
node tools/serve.js
```

브라우저에서 `http://localhost:8000`에 접속합니다. Node 서버는 `127.0.0.1`에 바인딩하며 `PORT` 환경변수로 포트를 변경할 수 있습니다.

Python을 사용할 수도 있습니다.

```sh
python -m http.server 8000
```

Windows의 `Play_Game.bat`는 Python 서버와 브라우저를 실행하므로 Python이 필요합니다. HTML 파일을 직접 여는 대신 HTTP 서버를 사용하세요. Three.js r128, fflate 0.8.2, FBXLoader와 웹 폰트를 외부에서 로드하므로 인터넷 연결도 필요합니다.

### PS 패드

브라우저에서 표준 매핑으로 인식되는 패드를 지원합니다. USB/블루투스로 연결한 뒤 게임 페이지에 포커스를 두고 버튼을 한 번 눌러 인식시킵니다. 연결 직후나 메뉴에서 복귀할 때 누르고 있던 버튼은 떼고 다시 눌러야 동작합니다.

| 입력 | 동작 |
| --- | --- |
| 왼쪽 스틱 | 피치·롤 (데드존 18%, 기울기에 비례한 조작) |
| 오른쪽 스틱 | 자유 시점 |
| L1 / R1 | 좌 / 우 요 |
| R2 / △ | 가속 / 감속 |
| ○ 탭 / 0.18초 이상 홀드 | 미사일 / 기관포. 탭 동작은 버튼을 뗄 때 실행 |
| L2 탭 / 0.28초 이상 홀드 | 타깃 변경 / 타깃 캠 |
| □ | 표준 → 멀티 → 표준 순차 전환 |
| × | 전투·정비창에서 스킬 카드창 열기 |
| Options | 옵션 열기·닫기 (강제 카드 선택 중에는 취소 불가) |
| 방향키, × 또는 ○ | 메뉴·카드 이동 및 선택. 정비창에서는 ×가 강화 전용이므로 출격은 ○로 선택 |

옵션의 음량 슬라이더는 방향키 위/아래로 포커스를 옮기고 좌/우로 조절합니다. 패드 연결 해제·창 포커스 이탈·메뉴 전환 시 패드 전투 입력을 초기화합니다. 표준 매핑이 없는 장치는 잘못된 버튼 작동을 피하기 위해 읽지 않습니다. 실제 PS4/PS5 패드의 브라우저별 연결·조작감 검증은 별도로 필요합니다.
## 전투와 성장

- 기관포 기본 피해는 18, 플레이어 미사일 기본 피해는 85이며 화력 보정을 받습니다. 기관포 HUD는 전방 200m에 레티클을 투영하고 1000m 이내 타깃에 55px 조준 보조 판정을 사용합니다. 이 값은 탄환의 실제 충돌 거리 제한이 아닙니다.
- 표준 미사일은 20발 탄창에서 한 발씩 발사하고 소진 후 10초에 전체 재장전합니다. 멀티는 16발 탄창에서 기본 최대 4발을 동시에 발사하고 소진 후 20초에 전체 재장전합니다. `멀티 관제 확장` 카드로 동시 락온·발사를 6발, 8발까지 늘릴 수 있습니다.
- 기본 락온 거리는 표준 2000m / 멀티 3000m이며 관제력으로 늘어납니다. 원뿔·거리 조건을 만족하면 즉시 락온하고, 락온 없이 쏘면 무유도로 직진합니다. 락온 거리는 미사일의 비행 거리 상한과 다릅니다.
- 처치 경험치를 즉시 받으며 레벨업마다 선택권 1회를 적립합니다. 레벨업 자체는 전투를 멈추지 않습니다.
- X로 카드창을 열거나 **웨이브 완료 후 미사용 선택권이 있으면 자동으로 카드창이 열립니다**. 열린 뒤에는 모든 선택권을 소비해야 복귀합니다. 선택마다 후보를 다시 추첨하고, 선택 중에는 전투와 재장전·전투 예약 타이머가 정지합니다.
- 기동력·안정성·속도·방어력·화력·관제력은 각각 0~5단계입니다. 미사일 랙은 단계당 탄창 +4발, 재장전 카드는 단계당 전체 재장전 시간 -10%입니다. 화력 3의 탄두, 관제력 3의 유도, 관제력 2의 멀티 관제 확장과 긴급 정비 카드도 구현되어 있습니다.
- 보스 처치 후 정비창에서 무료로 체력과 장전을 보충합니다. 미사용 선택권을 남긴 채 다음 배경으로 출격할 수 있으며 성장과 점수를 유지합니다. 마지막 정비창에서 출격 버튼을 누르면 런 완료입니다.
- 스테이지 선택 출격과 NEW RUN은 성장을 초기화합니다. 재도전은 해당 런을 시작했던 스테이지부터 시작합니다. 저장·영구 성장은 없습니다.

## 스테이지

현재 설정 원본은 `balance/waves_enemies.xlsx`입니다. 목표는 웨이브별 처치 수이며 고정된 편대 구성은 아닙니다.

| 스테이지 | 배경 | 웨이브별 목표 | 동시 존재 설정 | 공격 후보 설정 | 일반 공중 적 HP | 보스 HP |
| --- | --- | --- | --- | --- | --- | --- |
| CANYON SCOUT | 사막 | 35 / 40 / 45 | 30 | 4 | 80 | 2200 |
| OCEAN TRIDENT | 해상 | 45 / 50 / 55 / 60 | 36 | 5 | 100 | 3400 |
| METROPOLIS SHIELD | 도시 | 40 / 45 / 50 / 55 / 60 | 42 | 6 | 120 | 4800 |

일반 생성은 약 75% 확률의 절차적 드론, 약 25% 확률의 지상/해상 병력 분기입니다. 보스는 확대된 드론을 사용합니다. 공중 AI는 PATROL / INTERCEPT / ENGAGE / EVADE 상태와 지형 회피를 사용합니다.

전함은 선체와 함포 2개로 총 3개의 목표 슬롯을 사용합니다. 선체를 먼저 파괴하면 남은 함포도 연쇄 격파로 처리되어 목표·점수·경험치에 반영됩니다. 공격 후보 제한은 공중 적 사격에만 적용되고 탱크·함포에는 적용되지 않습니다. 상세 근거와 검증 공백은 [개발 문서](docs/ARCHITECTURE.md#현재-구현의-제한과-검증-공백)에 기록했습니다.

### 밸런스 기준 (2026-09-20)

표준/멀티 랙 카드는 단계당 탄창을 4발 늘리고, 멀티 관제 확장은 관제력 2에서 해금되어 동시 락온·발사를 4→6→8발로 늘립니다. 재장전 중 탄창 용량이 증가해도 완료 전 탄약은 지급되지 않습니다. 현재 웨이브 목표는 총 580기이며 스테이지 경험치 배율은 0.85 / 0.9 / 1.4입니다. 이벤트 기반 시뮬레이션 1,000회에서 균형 전략은 평균 19.31분, 종료 레벨 15.0, 카드 선택 14.0회였습니다.

## 최근 주요 업데이트 (2026-09-21)

### 1. 스마트 기총 어시스트 (Smart Gun Assist)
* **스마트 에임 시스템:** 에이스 컴뱃 스타일을 확장하여, 기총 사선 범위 내(점선 원형 UI)에 타깃의 리드 마커가 들어왔을 때 사격하면 기총의 에임과 탄도가 타깃을 향해 100% 자동 추적(스냅)되도록 구현했습니다. 
* **UI 연출:** 평상시에는 십자선이 고정되어 있으나, 발사 버튼을 누르고 있는 동안에만 에임이 타깃을 추적하는 동적 연출을 적용했습니다.
* **옵션 토글:** 시스템 설정(ESC 메뉴)에서 스마트 건 어시스트를 켜고 끌 수 있는 기능을 추가했습니다.
* **스킬 카드 연동:** \스마트 에임 확장 (smartAim)\ 장비 카드를 엑셀 밸런스 데이터에 추가했습니다. 랭크업 시 스마트 어시스트의 인식 반경이 20%씩 넓어집니다.

### 2. 미사일 리로드 시스템 개편 (Reload Debt)
* **동적 리로드 빚(Debt) 시스템:** 기존에는 탄창을 다 비운 시점부터 항상 일정한 고정 시간 동안 재장전해야 했으나, 이제는 한 발을 쏠 때마다 보이지 않는 '리로드 빚(시간)'이 추가됩니다.
* **자연 회복:** 사격하지 않고 기다리는 동안에는 이 리로드 빚이 서서히 줄어듭니다. 따라서 몇 발만 쏘고 충분히 기다렸다가 마저 쏘면, 탄창이 바닥났을 때의 최종 재장전 시간이 대폭 짧아집니다.
* **밸런싱 검증:** 내부 시뮬레이션(Balance Simulator)을 돌려 기총과 미사일 간의 DPS 점유율 및 스테이지 클리어 밸런스(표준/멀티/기총 비율 약 4:3:3)가 완벽하게 들어맞는 것을 확인했습니다.

### 3. 플레이어 격추(게임 오버) 연출 추가
* **3초 지연 폭발:** 플레이어의 체력이 0이 되어 격추되었을 때, 밋밋하게 바로 결과 창으로 넘어가지 않고 3초 동안의 파괴 연출을 추가했습니다. 
* 기체 형체가 사라지고 기존 속도의 관성으로 전진하면서 화려한 연쇄 폭발을 일으킨 뒤에 게임 오버 화면이 나타납니다.

### 4. 레이더 방향성 버그 수정
* 실제 위치와 레이더상의 적 방향이 일치하지 않던 문제를 수정했습니다.
* 이제 쿼터니언(Quaternion) 수학 모델을 사용하여, 전투기가 롤이나 피치 기동을 하더라도 내 기체 정면을 기준으로 정확하게 적의 상대적 위치를 레이더에 투영합니다.

### 5. 기타 편의성 및 밸런스 개선
* **초반 레벨업 속도 조정:** 1~4 레벨 구간의 필요 경험치를 낮추어 초반 성장이 빠르게 이루어지도록 엑셀 밸런스 테이블을 수정했습니다. (5레벨 이상은 기존 템포 유지)
* **효과음(SFX) 볼륨 조절:** 스킬 카드를 선택할 때 나오는 효과음의 볼륨이 너무 컸던 문제를 해결하기 위해 출력 볼륨을 30%로 낮췄습니다.
* **미사용 기능 제거:** 초기에 테스트용으로 도입되었으나 작동이 불안정했던 HUD 레이아웃 에디터를 시스템 파일에서 완전히 삭제하고 코드를 정리했습니다.

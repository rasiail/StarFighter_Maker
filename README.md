# StarFighter - 3D 플라이트 시뮬레이션 게임

Three.js를 기반으로 한 3D 전투기(F-104 Starfighter) 비행 슈팅 시뮬레이션 게임입니다.
복잡한 설치 과정 없이 웹 브라우저에서 바로 실행할 수 있으며, 아케이드 스타일의 조작감과 전투기 도그파이트를 경험할 수 있습니다.

---

## 1. 빠른 시작 (Quick Start)

### 주요 특징
- **기능별 모듈 구조**: HTML·CSS와 비행, 무장, AI, HUD, 오디오를 분리했습니다. 빌드 없이 브라우저 ES Modules로 실행합니다.
- **Three.js & Web Audio API**: Three.js r128, fflate, FBXLoader 및 폰트는 기존 CDN에서 로드하며 인터넷 연결이 필요합니다.
- **로컬 서버 환경 권장**: 텍스처(`Pic/`) 및 사운드(`Sound/`) 에셋 로딩을 위해 로컬 웹 서버 환경에서 실행해야 합니다.

### 실행 방법
1. **윈도우(Windows)**
   - 게임 디렉토리 내 `Play_Game.bat` 파일을 더블 클릭하여 실행합니다.
2. **또는 Python 로컬 서버 사용**
   ```bash
   python -m http.server 8000
   ```
   브라우저에서 `http://localhost:8000` 접속.
3. **Node.js로 실행**: `npm start` (의존성 설치 불필요). ES Modules를 사용하므로 HTML 직접 열기 대신 HTTP 서버를 사용합니다.

## 3. 조작 방법 (Controls)

| 분류 | 키 / 입력 | 설명 |
| :--- | :--- | :--- |
| **비행 조작** | **W / S** | 기수 하강(Pitch Down) / 기수 상승(Pitch Up) |
| | **A / D** | 기체 좌/우 회전 (Roll Left / Right) |
| | **Q / E** | 기수 좌/우 틀기 (Yaw Rudder) |
| **속도 제어** | **마우스 휠 (위/아래)** | 스로틀(기본 순항 속도) 80kts 단위 연속 조절 및 유지 |
| | **Shift / Alt** | 누르는 동안 최대 가속(Shift) / 최대 감속(Alt). 떼면 기본 순항 속도(550kts)로 점진적으로 복귀 |
| **무장/전투** | **Space / 마우스 좌클릭 홀드 (0.18초 이상)** | 20mm 기관포 발사 (사거리 1000m) |
| | **마우스 좌클릭 탭 (0.18초 미만)** | 유도 미사일 발사 |
| | **F** | 유도 미사일 발사 (키보드 전용) |
| | **1 / 2** | [1] 표준 미사일(사거리 2000m) / [2] 멀티 미사일(사거리 3000m) 무장 변경 |
| **타겟팅/시점**| **C / 마우스 우클릭 탭 (0.18초 미만)** | 다음 타깃으로 강제 변경(Cycle Target) |
| | **마우스 우클릭 홀드 (0.18초 이상) / T 키** | 락온된 적기를 쫓아가는 타깃 캠 모드 (손을 떼면 원상 복구) |
| | **마우스 이동 (포인터 락 상태)** | 기체 주변을 둘러보는 자유 시점 (Freelook). 멈추면 1.2초 뒤 정면 뷰 복귀 |
| **시스템** | **ESC** | 마우스 포인터 락 해제 / 옵션 메뉴 열기 |

*(※ 브라우저 탭 닫힘 방지를 위해 감속 키가 Ctrl에서 Alt로 변경되었으며, 강제 탭 종료(Ctrl+W) 시 경고창을 띄우는 안전장치가 적용되어 있습니다.)*

## 4. 게임 시스템 및 아키텍처 가이드

### 1) 기총 조준 시스템 (LCOS)
- **보어사이트 레티클 방식:** 타깃의 미래 위치를 계산하여 띄우던 기존 방식에서 벗어나, 기체 전방 200m에 **원형 HUD 레티클**이 고정되는 비행 슈팅 방식을 채택했습니다.
- **사거리 및 판정:** 기총의 유효 사거리는 **1000m**이며, 조준 판정 반경(55px)이 넉넉하여 호쾌하게 적을 타격할 수 있습니다.

### 2) 독립 타이머 미사일 재장전 시스템
모든 미사일 소진 시 클립 전체가 장전되던 방식에서, **한 발을 쏠 때마다 개별적인 리로드 타이머가 독립적으로 도는 현대식 시스템**으로 개편되었습니다.
- **[모드 1] 표준 미사일:** 최대 2발. 사거리 **2000m**. 발사 시 발당 **2.2초** 개별 장전.
- **[모드 2] 멀티 미사일:** 최대 4발(다중 락온 가능). 사거리 **3000m**. 발사 시 발당 **3.0초** 개별 장전.
- **HUD 인터페이스:** 현재 장전 중인 미사일 중 가장 먼저 완료될 미사일의 남은 시간을 표시하며, 장전된 잔탄 수(`[I.]`, `[II..]`)를 시각적으로 보여줍니다.

### 3) 적기(AI) 지형 회피 비행 시스템
- **자연스러운 지형 회피:** 기존의 강제 고도 점프(최저 650m 제한) 현상을 제거하고, 현재 비행 중인 지형(Ground) 기준으로 150m 상공을 자연스럽게 유지하며 비행합니다.
- 저고도에서도 덜컹거림 없이 완만하게 기수를 올리며 전투기다운 도그파이트 기동을 선보입니다.
- 플레이어와의 거리에 따라 `PATROL -> INTERCEPT -> ENGAGE -> EVADE` 의 상태로 전이하는 FSM 기반 유한 상태 기계 로직을 사용합니다.

### 4) 스테이지 구성
| 스테이지 | 전장 배경 | 등장 적 | 클리어 조건 |
| :--- | :--- | :--- | :--- |
| **STAGE 01: CANYON SCOUT** | 사막 협곡 | 공중 적 5기 + T-80 탱크 6기 | 10기 파괴 |
| **STAGE 02: OCEAN TRIDENT** | 해상 | 공중 적 7기 + 함대 3척 (선체+포탑 총 9개 타깃) | 20개 파괴 |
| **STAGE 03: METROPOLIS SHIELD** | 도시 | 공중 적 8기 + 탱크 8기 | 30기 파괴 |

## 5. 최적화 및 방어 코드
- **안전한 포인터 락 제어:** 탭을 벗어나거나 창이 가려질 때(`visibilitychange`), 실수로 브라우저 창을 닫으려 할 때(`beforeunload`) 강제로 포인터 락을 해제하고 마우스 커서 증발 현상을 방어합니다.
- **파티클 상한선 (Particle Ceiling):** 연쇄 폭발 시 심각한 프레임 드랍을 막기 위해 폭발 파티클(최대 500개) 및 미사일 연기 궤적(최대 280개)의 렌더링 개수를 엄격히 제한하고 있습니다.

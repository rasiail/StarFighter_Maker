# StarFighter - 3D 웹 도그파이트 시뮬레이션 게임

Three.js를 기반으로 제작된 브라우저 구동 3D 전투기(F-104 Starfighter) 도그파이트 슈팅 시뮬레이션 게임입니다.
본 문서는 다른 PC 환경이나 새로운 AI 코딩 어시스턴트가 프로젝트를 즉시 파악하고 원활하게 개발을 이어갈 수 있도록 상세한 아키텍처 및 개발 가이드를 제공합니다.

---

## 1. 프로젝트 개요 및 빠른 시작 (Quick Start)

### 주요 특징
- **단일 파일 기반 구조**: 메인 게임 엔진, 3D 렌더링, 비행 물리 시뮬레이션, 적 AI, HUD, 사운드 엔진, 브리핑/결과 UI가 `index.html`에 통합되어 있어 가볍고 빠른 실행이 가능합니다.
- **Three.js & Web Audio API**: 외부 무거운 프레임워크 의존성 없이 Three.js(r128) 라이브러리와 브라우저 표준 Web Audio API로 구현되었습니다.
- **로컬 웹 서버 구동 권장**: 사운드(`Sound/`) 및 이미지(`Pic/`) 정적 에셋 로딩을 위해 로컬 웹 서버 환경에서 실행해야 합니다.

### 실행 방법
1. **배치 파일 실행 (Windows)**
   - 루트 디렉토리의 `Play_Game.bat` 파일을 더블 클릭하여 실행합니다.
2. **또는 Python 내장 웹 서버 실행**
   ```bash
   python -m http.server 8000
   ```
   실행 후 브라우저에서 `http://localhost:8000` 접속.

## 4. 핵심 시스템 및 아키텍처 상세

### 1) 게임 루프 구조 (`animate()`)

```
animate()
  ├─ updatePlayerFlight(delta)   // 비행 물리, 속도, 기총/미사일 쿨다운
  ├─ updateEnemies(delta)        // 적 AI FSM (PATROL → INTERCEPT → ENGAGE → EVADE)
  ├─ updateSinkingShips(delta)   // 침몰 중인 전함 애니메이션
  ├─ updateProjectiles(delta)    // 총알/미사일/파티클 이동 및 충돌 판정
  ├─ updateCamera(delta)         // 카메라 피봇 보간, 타깃캠 / 디폴트 복귀
  └─ renderHUD()                 // 캔버스 HUD 전체 렌더링 (속도/고도/락온/LCOS/레이더)
```

**중요**: `isGameRunning && !isGamePaused` 조건 하에 전체 시뮬레이션이 동작하며 `try-catch`로 보호됩니다.

### 2) 기총 LCOS (Lead Computing Optical Sight) 시스템

에이스컴뱃 스타일의 기총 선도 조준 시스템입니다.

**작동 원리**:
1. 적기의 현재 속도와 방향 벡터(`eVel`)를 계산
2. 탄착까지 소요 시간(`flightTime = 거리 / 1600 m/s`)을 산출
3. **피퍼 위치 = `ePos + eVel * flightTime`** (적기가 탄착 시점에 있을 미래 위치를 직접 투영)
4. **기수 보어사이트** = `playerPos + playerFwd * 거리` 를 화면에 투영
5. 피퍼와 보어사이트 간 화면 픽셀 거리가 32px 미만 → `SHOOT` 경고 점멸 + 붉은색 전환

**피치 기동 연동**: 피퍼는 `playerFwd`에 무관한 순수 월드 좌표 계산이므로, 기수를 위로 올리면 적의 미래 위치가 상대적으로 화면 아래로 내려가며 피퍼도 정확히 따라 내려갑니다.

### 3) 마우스 입력 분기 구조
- `MOUSE_HOLD_THRESHOLD = 180` ms 기준 탭/홀드 분기
- 좌클릭 탭: `tryFireMissile()` 호출
- 좌클릭 홀드: `keys.fireCannon = true` → 게임 루프에서 매 프레임 `fireCannon()` 호출
- 우클릭 탭: `cycleTarget()`
- 우클릭 홀드: `keys.targetCam = true` → 타깃 포커싱 카메라

### 4) 오디오 엔진 (`SoundEngine`)
- **절차적 사운드**: Web Audio API 오실레이터로 제트 엔진음, 기관포음, 락온 경고음, 폭발음을 실시간 합성
- **타이틀/미션 BGM**: `Sound/DancingSky.mp3` — 메인 화면 및 미션 선택 화면
- **인게임 전투 BGM**: `Sound/StarFighter.mp3` — 출격 시 재생, 게임 오버/메인 메뉴 복귀 시 정지
- **전체 BGM 볼륨 기본값**: 60% (`bgmVolume: 0.6`)

### 5) 적 AI FSM (Finite State Machine)
| 상태 | 전환 조건 | 행동 |
| :--- | :--- | :--- |
| PATROL | 2600m 이내 접근 시 INTERCEPT | 설정된 순찰 포인트로 비행 |
| INTERCEPT | 2200m 이내 → ENGAGE | 플레이어를 향해 전속 추격 |
| ENGAGE | 3200m 이상 이탈 → INTERCEPT | 기관포/미사일 동시 운용, 500m 이내 선회 회피 |
| EVADE | 타이머 소진 → INTERCEPT | 측방 분리 기동 후 복귀 |

이탈 방지: 6500m 이상 이탈 시 플레이어 전방으로 즉시 순간이동(Leashing)

### 6) 스테이지 구성
| 스테이지 | 배경 | 지상 목표 | 공중 적기 |
| :--- | :--- | :--- | :--- |
| STAGE 01: CANYON SCOUT | 사막 | T-80 전차 6대 | 5기 |
| STAGE 02: OCEAN TRIDENT | 해양 | 전함 3척 (함체+함포 각 3개 타깃) | 7기 |
| STAGE 03: METROPOLIS SHIELD | 도시 | T-80 전차 8대 | 8기 |

## 5. 차기 개발 시 AI 가이드라인 및 주의사항

1. **사용자 언어 규칙 (Global Rule)**
   - 사용자와의 모든 대화, 설명, 코드 주석, 피드백은 반드시 **친절하고 명확한 한국어**로 작성합니다.

2. **마크다운 문서 갱신 정책**
   - `README.md`는 사용자가 명시적으로 요청할 때만 갱신합니다. 임의 갱신 금지.

3. **조작 방식 확정 사항 (변경 금지)**
   - 마우스 좌클릭 **단발 탭** (0.18초 미만) = 미사일 발사
   - 마우스 좌클릭 **홀드** (0.18초 이상) = 기관포 연사
   - `MOUSE_HOLD_THRESHOLD = 180` (ms) 상수는 변경 금지

4. **포인터 락 상태 제어 보존**
   - `requestPointerLock` / `exitPointerLock` 로직 및 `wasPointerLocked` 플래그를 손상시키지 마십시오.

5. **대용량 단일 파일(`index.html`) 편집 주의**
   - 코드 수정 후 반드시 `node -c` 구문 검사를 실행하여 오류 여부를 확인하십시오.

6. **사운드 자동재생 정책 대응**
   - 유저 인터랙션 시 `SoundEngine.init()` 및 오디오 컨텍스트 `resume()`이 동작하도록 유지하십시오.

7. **파티클 성능 관리**
   - `triggerExplosion()`: 파티클 500개 상한 적용
   - `createSmokePuff()`: 280개 상한 적용
   - 수정 시 이 상한선을 유지하세요.

## 6. 알려진 제한 사항 및 향후 과제

- 현재 모든 로직이 `index.html` 단일 파일에 구현되어 있어, 레벨링/스탯/업그레이드 시스템 추가 시 파일 분리(모듈화) 리팩토링 검토 필요
- 적 AI는 단순 FSM 기반으로, 편대 전술 및 고급 회피 기동 추가 가능
- 모바일 터치 조작 기본 지원 중 (가상 조이스틱, 기총/미사일 터치 버튼)

# StarFighter - 3D 웹 도그파이트 시뮬레이션 게임

Three.js를 기반으로 제작된 브라우저 구동 3D 전투기(F-104 Starfighter) 도그파이트 슈팅 시뮬레이션 게임입니다.  
본 문서는 다른 PC 환경이나 새로운 AI 코딩 어시스턴트가 프로젝트를 즉시 파악하고 원활하게 개발을 이어갈 수 있도록 상세한 아키텍처 및 개발 가이드를 제공합니다.

---

## 1. 프로젝트 개요 및 빠른 시작 (Quick Start)

### 주요 특징
- **단일 파일 기반 구조**: 메인 게임 엔진, 3D 렌더링, 비행 물리 시뮬레이션, 적 AI, HUD, 사운드 엔진, 브리핑/결과 UI가 `index.html`에 통합되어 있어 가볍고 빠른 실행이 가능합니다.
- **Three.js & Web Audio API**: 외부 무거운 프레임워크 의존성 없이 Three.js 라이브러리와 브라우저 표준 Web Audio API로 구현되었습니다.
- **로컬 웹 서버 구동 권장**: 사운드(`Sound/`) 및 이미지(`Pic/`) 정적 에셋 로딩을 위해 로컬 웹 서버 환경에서 실행해야 합니다.

### 실행 방법
1. **배치 파일 실행 (Windows)**
   - 루트 디렉토리의 `Play_Game.bat` 파일을 더블 클릭하여 실행합니다.
2. **또는 Python 내장 웹 서버 실행**
   ```bash
   python -m http.server 8000
   ```
   실행 후 브라우저에서 `http://localhost:8000` 접속.


## 3. 게임 조작법 (Controls)

| 분류 | 키 / 입력 | 동작 설명 |
| :--- | :--- | :--- |
| **비행 제어** | **W / S** | 기수 하강(Pitch Down) / 기수 상승(Pitch Up) |
| | **A / D** | 롤 좌/우 회전 (Roll Left / Right) |
| | **Q / E** | 요/러더 좌/우 회전 (Yaw Rudder) |
| | **Shift / Ctrl** | 스로틀 증가(가속) / 스로틀 감소(감속 및 에어브레이크) |
| | **마우스 이동** | 화면 내 가상 전투 크로스헤어 조준 |
| **무장 발사** | **Space / 마우스 좌클릭 (Hold)** | 20mm M61 벌컨 기관포 연사 |
| | **F / 마우스 좌클릭 (Tap)** | AIM-9 사이드와인더 공대공 유도 미사일 발사 |
| | **1 / 2** | 표준 단발 미사일 / 멀티 미사일 모드 전환 |
| **타깃 & 시점** | **C / 마우스 우클릭 (단발 탭, 0.2초 미만)** | 다음 적기 타깃 락온 순환 |
| | **마우스 우클릭 (홀드, 0.2초 이상) / T 키** | **타깃 포커싱 카메라** (360도 전방위 추적, 격추 시 차기 적기 자동 인계, **우클릭/T키 해제 시 전투기 후방 디폴트 시점 부드럽고 신속한 자동 복귀**) |
| **시스템** | **ESC** | 마우스 포인터 락 해제 및 게임 일시정지 / 옵션 메뉴 |

## 4. 핵심 시스템 및 아키텍처 상세

### 1) 마우스 포인터 락 & 가상 전투 조준선 (`#virtual-cursor`)
- **창 내부 감금**: 인게임 돌입 시 브라우저 `requestPointerLock()`을 호출하여 마우스가 게임 화면 밖으로 이탈하지 않도록 감금합니다.
- **실시간 가상 커서**: 물리 마우스가 잠긴 상태에서 `movementX`, `movementY`를 누적 계산한 `virtualMouse` 좌표를 기반으로 SVG 기반 전투 크로스헤어(`#virtual-cursor`)를 화면에 매끄럽게 렌더링합니다.
- **안전 해제**: `ESC`를 누르거나 게임 일시정지, 스테이지 클리어/실패 시 포인터 락이 안전하게 해제되어 일반 UI 마우스 조작으로 자동 복귀합니다.
- **옵션 팝업 방어**: 출격 시 불필요하게 옵션창이 트리거되지 않도록 `wasPointerLocked` 상태 플래그로 보호합니다.

### 2) 타깃팅 & 스마트 포커싱 카메라 시스템
- **굵고 선명한 타깃 UI**: 적기 락온 사각 프레임 및 리드샷 예측 링의 스트로크를 굵게 강화하여 전투 가시성을 높였습니다.
- **360도 전방위 포커싱 (우클릭 Hold)**: 기체 방향과 상관없이 쿼터니언 기반 구면 선형 보간(`slerp`)을 적용하여 락온된 적기를 부드럽게 화면 중앙에 고정합니다.
- **격추 시 자동 인계 (`acquireNextBestTarget`)**: 포커싱 중이던 적기가 파괴되면 카메라가 엉뚱한 곳을 보지 않고 즉시 가장 가까운 생존 적기를 탐색하여 부드럽게 시점을 인계합니다.
- **디폴트 시점 자동 복귀**: 우클릭 홀드를 해제하면 잔류 각도 고정 없이 최단 경로 각도 보간(`diffYaw`, `lerp`)을 통해 전투기 후방의 정면 디폴트 시점(`cameraPivot (0, 0, 0)`)으로 매끄럽고 즉각 복귀합니다.

### 3) 오디오 엔진 (`SoundEngine`)
- **절차적 사운드 (Procedural Audio)**: Web Audio API 오실레이터 및 노이즈 버퍼를 조합하여 제트 엔진 추진음, 기관포 사운드, 락온 경고음, 폭발음을 실시간 합성 생성합니다.
- **타이틀/미션 전용 BGM**: `Sound/DancingSky.mp3` 파일을 사용하여 메인 화면 및 미션 선택 브리핑 단계에서 재생됩니다.
- ⚠️ **[중요 제약사항]**: 사용자 명시 요청에 따라 **인게임 비행 중에는 BGM을 재생하지 않습니다** (`SoundEngine.startFlightAudio()` 내부의 BGM 시작 코드는 주석 처리되어 엔진 및 효과음만 몰입감 있게 출력).

### 4) 전장 환경 및 시각 효과
- **사막 전장 색감 최적화**: 사막 지형의 채도(Saturation)를 톤다운하여 눈부심을 줄이고 적기와 HUD 타깃 UI의 대비를 극대화했습니다.
- **메인 타이틀 비주얼**: `Pic/StarFighterTitle.jpeg` 배경에 다크 틴트 딤드(Dimmed) 효과 및 글래스모피즘(Glassmorphism) 브리핑 패널을 적용하여 고급스러운 군사 브리핑 분위기를 연출했습니다.

### 5) 스테이지 진행 및 클리어 모달
- 스테이지 목표 달성 시 클리어 모달이 팝업되며 다음 기능이 제공됩니다:
  - **[다음 스테이지] 버튼**: 다음 작전 지역 및 추가 적 편대 출격
  - **[메인 화면] 버튼**: 타이틀 화면으로 복귀하여 BGM 재시작 및 미션 재선택 가능

## 5. 차기 개발 시 AI 가이드라인 및 주의사항

새로운 AI 어시스턴트나 개발자는 코드 작업 시 다음 규칙을 반드시 준수해야 합니다:

1. **사용자 언어 규칙 (Global Rule)**
   - 사용자와의 모든 대화, 설명, 코드 주석, 피드백은 반드시 **친절하고 명확한 한국어**로 작성합니다.
2. **인게임 BGM 임의 추가 금지**
   - 사용자가 명시적으로 "인게임에 BGM을 추가해달라"고 요청하기 전까지는 **인게임 비행 중 BGM을 재생하지 않아야 합니다.**
3. **포인터 락 상태 제어 보존**
   - UI 팝업(옵션창, 일시정지, 클리어 모달)과 인게임 진입 간의 `requestPointerLock` / `exitPointerLock` 로직 및 `wasPointerLocked` 플래그를 손상시키지 마십시오.
4. **대용량 단일 파일(`index.html`) 편집 주의**
   - 주요 모듈이 `index.html`에 집약되어 있으므로, 코드 수정 시 기존 전역 객체(`gameState`, `SoundEngine`, `flightData`, `targetSystem` 등)의 참조가 깨지지 않도록 부분 수정(`replace_file_content`) 시 범위를 정밀하게 지정하십시오.
5. **사운드 자동재생 정책 대응**
   - 최신 브라우저의 오디오 자동재생 제한(Autoplay Policy)을 준수하기 위해 유저 인터랙션(스타트 클릭, 키 입력 등) 시 `SoundEngine.init()` 및 오디오 컨텍스트가 `resume`되도록 유지하십시오.
